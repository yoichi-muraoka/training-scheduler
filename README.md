# 講座スケジュール管理システム

本プロジェクトは、講義内容（カリキュラム）と実際の日付を分離して管理することで、休講日の反映や日程調整を容易に行える講座スケジュール管理システムのプロトタイプ（ドキュメントベース）です。

目的
- 休講日や日程変更に強いスケジュール管理を実現し、安定したレイアウトでPDFを出力できることを目指します。

主な機能（要件）
- 講座の基本情報管理（講座名、年度、開始/終了日、休講日、講義時間、ヘッダー/フッター等）
- 講義区分管理（区分ごとに連番付与）
- 再利用可能な講義（コンテンツ）管理
- 1日分の講義ブロック作成（複数講義の順序保持）
- スケジュール管理（ドラッグ＆ドロップで並び替え、休講日を除いた自動日付割当）
- ブラウザ印刷によるPDF出力（A4縦、ヘッダー/フッター、表形式レイアウト）

想定利用者
- カリキュラム作成・調整担当者
- 講師・配布資料作成担当者

技術スタック（想定）
- フロントエンド: HTML / CSS / JavaScript（Vite）
- データ: json-server（プロトタイプ）
- 出力: ブラウザ印刷機能（PDF保存）

簡単なセットアップ（プロトタイプ）
- このリポジトリはドキュメント中心です。動作検証を行う場合は、フロントエンドの雛形を用意し、`json-server` を使ってデータを用意してください。
