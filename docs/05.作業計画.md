# 講座スケジュール管理システム
作業計画（段階的開発）

目的：
- 一気に作り切らず、**常に「動くもの」を確認しながら**開発を進める
- 各ステップで「戻れる」「直せる」状態を維持する
- Word運用の置き換えとして、最低限でも価値が出る段階を早く作る

---

## フェーズ0：準備・土台づくり（最初に必ずやる）

### ゴール
- 開発環境が立ち上がり、画面が表示される
- APIと通信できる状態になる

### 作業内容
- Vite + React プロジェクト作成 ✅
- Chakra UI 導入・テーマ設定 ✅
- React Router 設定 ✅
- TanStack Query 初期化 ✅
- Axios インスタンス作成 ✅
- json-server 起動（db.json 仮データ）✅

### 確認ポイント
- `/courses` にアクセスすると画面が表示される
- json-server に GET リクエストが通る ✅

---

## フェーズ1：講座一覧・講座設定（最小価値の提供）

### ゴール
- 講座の基本情報と休講日を登録・編集できる
- 「6/1を休講」にして保存できる

### 作業内容
- 講座一覧画面（CoursesListPage）
- 講座設定画面（SettingsPage）
  - 講座名・年度・期間
  - 講義時間
  - 備考
  - 印刷ヘッダー／フッター
- 休講日CRUD
- 休講日表示トグル（Atom）

### 確認ポイント
- 休講日を追加・削除できる
- 保存後、再読み込みしてもデータが残る

---

## フェーズ2：講義区分・講義マスタ（部品づくり）

### ゴール
- 講義の「部品」が揃う
- 説明（detail）付き講義を管理できる

### 作業内容
- 講義区分管理画面（CategoriesPage）
- 講義管理画面（LecturesPage）
  - 区分選択
  - 講義名
  - 説明（detail）

### 確認ポイント
- 区分を追加・削除できる
- 講義を区分付きで登録できる
- detail が正しく保存・表示される

---

## フェーズ3：1日ブロック管理（構成の単位）

### ゴール
- 「1日分の講義セット」を作れる
- 並び順を自由に変えられる

### 作業内容
- 1日ブロック一覧・編集画面（DayBlocksPage）
- 講義選択UI（検索付き）
- ブロック内講義の並び替え（D&D or ボタン）

### 確認ポイント
- 複数講義をまとめたブロックが作れる
- 並び順を変えても保存される

---

## フェーズ4：スケジュール編集（自動割当の核心）

### ゴール
- 並び替えるだけで日付が自動割当される
- 休講日トグルが効く

### 作業内容
- スケジュール画面（SchedulePage）
- 見出し（基礎編／応用編）追加
- ブロックの並び替え
- `buildSchedule` 実装
  - 開始日から割当
  - 土日スキップ
  - 休講日スキップ
- 区分連番ロジック（①②…）

### 確認ポイント
- 6/1を休講にすると、日付が自動で詰まる
- トグルONで「休講」行が見える
- 並び順変更後も正しい日付になる

---

## フェーズ5：印刷プレビュー（PDF完成形）

### ゴール
- Wordと同等の見た目でPDF出力できる
- クライアントにそのまま渡せる

### 作業内容
- 印刷画面（PrintPage）
- 印刷用モデル生成（buildPrintModel）
- A4印刷CSS（print.css）
- ヘッダー／フッター表示
- 区分名＋連番表示

### 確認ポイント
- ブラウザ印刷でA4 PDFが正しく出る
- 休講日表示トグルが印刷にも反映される
- 講義説明（detail）がPDFに出る
