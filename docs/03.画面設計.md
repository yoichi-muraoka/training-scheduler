# 講座スケジュール管理システム 画面設計

## 1. 画面一覧

1. 講座一覧 `/courses`
2. 基本情報（講座設定） `/courses/:id/settings`
3. 講義区分管理 `/courses/:id/categories`
4. 講義管理（講義マスタ） `/courses/:id/lectures`
5. 1日ブロック管理 `/courses/:id/day-blocks`
6. スケジュール管理（D&D） `/courses/:id/schedule`
7. 印刷プレビュー（A4/PDF） `/courses/:id/print`

---

## 2. 画面遷移（ユーザーフロー）

- 講座一覧
  - 新規作成 → 講座設定
  - 講座を開く → （講座内ナビで）設定／区分／講義／ブロック／スケジュール／印刷

標準運用
1) 設定（期間・休講日）  
2) 区分 → 講義（detail含む） → 1日ブロック  
3) スケジュール（D&D）  
4) 印刷 → PDF

---

- 設定

- 講義

- スケジュール
- 印刷

## 4. 各画面設計

## 4.1 講座一覧 `/courses`

目的：講座の作成・選択

UI
- [＋ 新規講座]
- 講座一覧（カード/表）
  - 講座名 / 年度 / 期間
  - [開く] [複製] [削除]

## 4.2 基本情報（講座設定） `/courses/:id/settings`

目的：講座の基本情報、休講日、印刷用ヘッダー/フッターを管理

UI（フォーム）
- 講座名（テキスト）
- 年度（数値）
- 開始日 / 終了日（日付）
- 講義時間（開始/終了：time input）
- 備考（テキストエリア）
- 印刷ヘッダー（テキストエリア：複数行可）
- 印刷フッター（テキストエリア：複数行可）
- [保存]

休講日セクション
- 休講日一覧（テーブル）
  - 日付 / 種別（祝日・お盆・臨時）/ ラベル / [削除]
- [＋休講日追加]
  - 日付ピッカー、種別、ラベル
- （任意）[祝日テンプレ投入]
- ※ 休講日はスケジュール／印刷に自動反映（再割当は表示側で計算）

## 4.3 講義区分管理 `/courses/:id/categories`

目的：区分（例：Javaプログラミング実習、React実習）を管理

UI
- 区分一覧（表）
  - 区分名 / [編集] [削除]
- [＋区分追加]

補足
- 区分番号（①②…）は「スケジュール上の登場順」で採番するため、
  区分自体の並び替えは必須ではない（必要なら将来追加）

## 4.4 講義管理（講義マスタ） `/courses/:id/lectures`

目的：講義をマスタとして管理（ブロックに組み込んで再利用）

講義マスタ項目
- 講義名（name）
- 区分（categoryId）
- 説明（detail）※印刷に出る本文

UI
- フィルタ

- 講義一覧（表）
  - 講義名 / 区分 / 説明（折りたたみ表示）/ [編集] [削除]
- [＋講義追加]
  - 講義名、区分、説明（複数行）
- （任意）CSV一括登録（将来）

## 4.5 1日ブロック管理 `/courses/:id/day-blocks`

目的：1日分の講義セット（ブロック）を作成する  
※ dayBlock に「タイトル入力」は不要。表示は区分名＋連番で表現する。

dayBlock が持つ情報
- 区分（categoryId）
- 講義の並び（lectureIdsの配列）

UI（2ペイン推奨）
- 左：ブロック一覧
  - 表示名：`{区分名}（講義数: n）`
  - [編集] [複製] [削除]
- 右：ブロック編集
  - 区分（プルダウン）
  - 講義追加（検索付きセレクト）
    - 講義名（＋必要なら detail をツールチップ/プレビュー表示）
    - [追加]
  - ブロック内講義リスト
    - D&Dで並び替え
    - [削除]
  - [保存]

---

## 4.6 スケジュール管理（D&D） `/courses/:id/schedule`

目的：
- dayBlock と見出し（基礎編/応用編）をD&Dで並べ替える
- 休講日を考慮して日付を自動割り当てる
- 休講日はトグルで表示ON/OFF

UI（上部：コントロール）
- [＋見出し追加]（例：基礎編）
- [＋ブロック追加]（dayBlocksから選択）
- 休講日表示：トグル（ON/OFF）
- 集計表示（任意）
  - 期間、休講日数、稼働日数、必要日数（dayBlock件数）
- [保存]（並び順を保存）

UI（メイン：D&Dリスト）
- 行の種類
  - 見出し（section）
  - 1日ブロック（dayBlock）
  - 休講日（holiday）※表示ONのときのみ行として出す
- 行の表示例（左→右）
  - D&Dハンドル（⋮⋮）
  - 日付＋曜日（自動割当結果）
  - 内容
    - section：見出し名
    - dayBlock：`{区分名}{連番}`（例：Javaプログラミング実習①）
    - holiday：`休講（ラベル）`
  - 操作：[…]（削除/編集など）

日付割当ルール（表示ロジック）
- 開始日から順に走査
- 土日をスキップ（設定でONの場合）
- 休講日はスキップし、トグルONの時だけ「休講行」として表示する
- dayBlock 行のみ日付を消費する
- section 行は日付を消費しない

区分連番（①②…）ルール
- スケジュールを上から走査し、
  dayBlock の categoryId ごとに登場回数をカウントして採番
- 表示名：`{区分名}{連番}`

---

## 4.7 印刷プレビュー（A4/PDF） `/courses/:id/print`

目的：A4で、ヘッダー/フッター付きのPDFを出力する

UI（非印刷領域：画面上部）
- 休講日表示：トグル（ON/OFF）※スケジュール画面と同じ意味
- [印刷]（window.print）

印刷領域（印刷対象）
- ヘッダー（講座設定の printHeader を表示）
- 本文（表形式）
  - 日付（休講表示ONの場合は休講日も行として出る）
  - 時間（例：9:00〜18:00）
  - 内容
    - dayBlock：`{区分名}{連番}` を見出しとして表示
      - その下に講義一覧を表示
        - 講義名
        - 講義説明（detail）
    - section：見出し（基礎編/応用編）
    - holiday：休講（ラベル）
- フッター（講座設定の printFooter を表示）

印刷仕様（CSS）
- A4縦
- 余白、改ページ、罫線を @media print で制御
- ヘッダー/フッターは各ページに表示（※実現方式は実装で検討）

---

## 5. 画面設計における補足（実装の方針）

- dayBlock は「区分＋講義並び」のみで管理し、タイトル入力をなくす
- 講義の説明は講義マスタ（detail）に集約し、印刷もそこを参照する
- 休講日は「データとしてスキップ」し、表示したいときだけトグルで行として出す
- 日付割当はDBに保存せず、表示時に計算（休講追加や並び替えに強い）
