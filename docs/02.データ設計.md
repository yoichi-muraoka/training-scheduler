# データ設計（要点）

## テーブル構成
### courses
- 講座の基本情報（ヘッダー/フッター/備考/期間/時間/休講ポリシー）

### holidays
- 「休講日」を日付単位で追加できる（例：6/1を臨時休講にする）

### categories / lectures
- 区分（例：React実習）と講義（例：フック）をマスタ管理

### dayBlocks
- 1日分の講義ブロック（講義を組み合わせて作る部品）
- lectureItems は lectureId の参照が基本
-ただし、PDFと同じように「見出し＋詳細」を持つ講義もあるので、label/detail を直接持つ形式も許容（互換性のため）

### scheduleItems
- D&D対象の「並び順」そのもの
- type: section で「基礎編/応用編」見出しを動かせる
- order を保存して並び順を安定化

## 補足
-　日付の自動割当は “保存しない” 
- 要件の「休講日以外の日付が順番に自動割り当て」は、scheduleItems（順序）, courses.startDate / endDate, holidays から、画面表示時に 毎回計算 するのが堅牢。（休講日が増減した時に、日付データの更新地獄にならないため）
